# Sunday Reset

Thirty minutes that make Monday boring, in the good way. This is the kind of list you run every week — and the kind that gets better every week, because each run teaches you which items earn their place and which don't. Delete freely. Add reluctantly.

## Look back

- [ ] Empty pockets, bags, and the car of the week's debris
- [ ] Inbox to zero-ish — reply, file, or let go
- [ ] Anything you borrowed, promised, or half-finished — write it down

## Reset the space

- [ ] Laundry in motion
- [ ] Fridge audit — toss what died, note what's missing
- [ ] Ten-minute surface sweep of the rooms you actually live in

## Look ahead

- [ ] Calendar scan for the week — any landmines?
- [ ] Pick the one thing that would make this week a win
- [ ] Meals — 0/5 weeknights with a plan
- [ ] Charge everything
