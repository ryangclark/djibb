# One-Bag Weekend Trip

Two nights, one carry-on, zero "did I forget my charger" moments. The counts are for a 2-night trip — fork it and retune the numbers for a week, a wedding, or a winter destination. The list is the same; the context isn't.

## Clothes

- [ ] Socks — 0/3 pairs
- [ ] Underwear — 0/3
- [ ] Shirts — 0/3
- [ ] One layer warmer than the forecast says you need
- [ ] Shoes you can walk all day in

## Toiletries

- [ ] Toothbrush and toothpaste
- [ ] Deodorant
- [ ] Medications — counted out, plus one spare day
- [ ] Contacts or glasses, plus backup

## Tech

- [ ] Phone charger
- [ ] Battery pack, charged
- [ ] Headphones

## Before you walk out

- [ ] Wallet, keys, ID — physically touch all three
- [ ] Trash out, dishes done — future you says thanks
- [ ] Thermostat set, lights off
- [ ] Doors and windows locked
