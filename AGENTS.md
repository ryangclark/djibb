# AGENTS.md

Guidance for agents working in this repo.

## Agent skills

### Issue tracker

Issues are tracked as GitHub issues in `ryangclark/djibb` (via the `gh` CLI). External PRs are **not** a triage surface. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary — `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Multi-context: shared glossary in `CONTEXT.md`, routed by `CONTEXT-MAP.md`, with per-context `CONTEXT.md` files created lazily. See `docs/agents/domain.md`.
